# 晗晗的方特大冒险

手机端优先的亲子冒险地图。使用纯 HTML、CSS 和 JavaScript 构建，无需后端；闯关状态保存在 localStorage，照片和录音保存在 IndexedDB。

## 在线体验

<https://173800607-hash.github.io/kids-adventure-map/>

## 本地预览

可以直接双击 `index.html` 打开。更推荐在项目目录运行随项目提供的本地预览服务：

```powershell
node server.mjs
```

然后访问 <http://localhost:4173>。

任务完成状态和文字记录保存在浏览器 localStorage 中。
